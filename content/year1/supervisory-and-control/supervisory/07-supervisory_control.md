# Supervisory Control

## Introduction

The field of supervisory control was largely founded by _Ramadge and Wonham_ in 1989. Their goal was to define a general framework for the control of _logical, discrete event systems_.

They devised a general scheme which consists of two components:

* A **plant**, which is the system to be controlled
* A **supervisor**, which has the objective of controlling and limiting the evolution of the plant. Note that a supervisor _cannot_ extend the behavior of the system, but only limit it.

## Components of the feedback control scheme

The above definition allows us to defined a close loop, in which the supervisor influences the plant's evolution:

![](https://i.imgur.com/2ORT68n.png)

We give each component a formal definition:

> [!info] Plant
> 
> A plant is a process $G$ to be controlled. Its behavior is described as a language (a set of events) generated on an alphabet $E$. We can thus have:
> 
> * Plants with **closed behavior**: in which $L(G) \subseteq E^*$, meaning that the generated language is _prefix-closed_ and composed by a set of sequences of events occurring in the system.
> * Plants with **marked behavior**: in which $L_m(G) \subseteq L(G)$, meaning that the generated language is composed by a set of sequences of events occurring in the system, corresponding to the _completion of a specific task_.

We use a DFA to model $G$: the closed behavior is represented by the generated $L(G)$, while the marked one by the accepted $L(G)$.

> [!info] Events
> 
> The alphabet of events $E$ is defined as:
> 
> $$
> E = E_c \cup E_{uc} \text{    with } E_c \cap E_{uc} = \emptyset
> $$
> 
> where:
> * $E_c$ is the set of _controllable_ events
> 	* Here, the plant can **disable** the execution of an event $e \in E_c$ when it is about to fire.
> * $E_{uc}$ is the set of _uncontrollable_ events
> 	* Here, on the contrary, the plant **can't disable** the execution of an event  $e' \in E_{uc}$ when it is about to fire.

Graphically, we denote _controllable events_ with a `:` symbol.

> [!info] Active event
> 
> In a DFA $G$, for each state $x \in X$ the set of active events in $G$ for a state $x$ is:
> 
> $$
> A_G(x) = \{s \in E \mid \delta(x,s) \text{ is defined}\}
> $$
> 
> while for a word $w \in L(G)$, the set of active events after $w$ is:
> 
> $$
> A_G(w) = \{e \in E \mid we \in L(G)\}
> $$

> [!help] Clarification
> 
> In this case, both $A_G(w)$ functions indicate two different mappings: one $A_G : X \to 2^E$ and one $A_G : L(G) \to 2^E$. It follows that if we can reach a state $x$ from $x_0$ generating a word $w$, then $A_G(w) = A_G(x)$.
> 
> Basically, we can either express that an event is active (which means that the state is reachable) from a state (the first definition), or that it is active from a word (the second one). See below for an example.

As an example, consider the following DFA with $E_c = \{a,b,d,f\}, E_{uc} = \{c,e\}$:

![](https://i.imgur.com/Vdjvwmk.png)

We say that this DFA represents a printing machine, where the states are:

* $x_0$: idle
* $x_1$: ready
* $x_2$: printing
* $x_3$: offline

and the events are:

* $a$: inking (controllable)
* $b$: start printing (controllable)
* $c$: finish printing successfully (**uncontrollable**)
* $d$: stop printing (controllable)
* $e$: printing error (**uncontrollable**)
* $f$: maintenance (controllable)

Considering active events, we have:

* $A_G(\epsilon) = A_G(x_0) = \{a\}$
	* _Starting from $x_0$, which means that we have not produced a word yet ($\epsilon$), the only active event is $a$_
* $A_G(a) = A_G(x_1) = \{b,d\}$
	* _Starting from $x_1$, or, alternatively, having produced $a$, the only active event are $b,d$_
* $A_G(ab) = A_G(x_2) = \{c,e\}$
	* _Starting from $x_2$, or, alternatively, having produced $ab$, the only active events are $c,e$_
* ...and so on

> [!info] Supervisor
> 
> Once a word $w \in L(G)$ has been generated by a plant, the supervisor can either:
> 
> * Disable it, **only if** the event is controllable: $e \in A_g(w) \cap E_c$. This basically prevents the event from occurring
> * Can't disable it, if the event is uncontrollable: $e' \in A(w) \cap E_{uc}$.
>   
> Formally, we define $S$ as a supervisor controlling a plant $G$ as a control function:
> 
> $$
> f : L(G) \to 2^E
> $$
> 
> that generates a sequence of admissible control inputs:
> 
> $$
> \xi_0 = f(\epsilon), \xi_1 = f(e_1), \xi_2 = f(e_1e_2), \dots
> $$
> 
> in response to the events $w = e_1e_2\dots \in L(G)$ generated by $G$.

Events not disabled by a supervisor are called "**enabled**".

> [!info] Control inputs
> 
> Given a plant $G$ on an alphabet $E$, a _control input_ is a subset of events $\xi \subseteq E$:
> * if $e \in \xi$, then $e$ is _enabled by the supervisor_
> * if $e \not\in \xi$, then $e$ is _disabled_
> 
> All set of inputs are denoted as $2^E$.

Uncontrollable events can't, by definition, be stopped by a supervisor: this means that a control input $\xi$ is admissible after $w$ only if $E_{uc} \cap A_G(w) \subseteq \xi$, meaning that it contains all uncontrollable events that are active in $G$ after $w$.

Taking the example system from above, we have that:
* $\xi = \{a,b,c\}$ is admissible after $a$, since $A_G(a) = \{b,d\}$ and $A_G \cap E_{uc} = \emptyset \subseteq \xi$.
* However, $\xi = \{a,b,c\}$ is not admissible after $a,b$, since $A_G(ab) = \{c,e\}$, $A_G \cap E_{uc} = \{c,e\}$, and this does not include the uncontrollable, active event $e$.

Concluding our printing machine example, say that we want to add a supervisor $S$ so that each time the press is inked, at most _one_ printing operation can be performed. This translates to the following statement on a DFA: 

> After each $a$, at most one $b$ may occur, until a new $a$ is observed.


| $w$        | $x$     | $\xi = f(w)$      |
| ---------- | ------- | ----------------- |
| $\epsilon$ | $x_0$   | $\{a,b,c,d,e,f\}$ |
| $a$        | $x_1$   | $\{a,b,c,d,e,f\}$ |
| $ab$       | $x_2$   | $\{a,c,d,e,f\}$   |
| $abc$      | $x_1$   | $\{a,c,d,e,f\}$   |
| $abcd$     | $x_3$   | $\{a,c,d,e,f\}$   |
| $abcdf$    | $x_0$   | $\{a,c,d,e,f\}$   |
| $abcdfa$   | $x_1$   | $\{a,b,c,d,e,f\}$ |
| $\dots$    | $\dots$ | $\dots$           |
| $ad$       | $x_3$   | $\{a,b,c,d,e,f\}$ |
| $adf$      | $x_0$   | $\{a,b,c,d,e,f\}$ |
| $adfa$     | $x_1$   | $\{a,b,c,d,e,f\}$ |
| $\dots$    | $\dots$ | $\dots$           |

In steps $2$ to $6$, we define the set of active events $\xi$ as any possible state reachable from the currently composed word, but we remove $b$, since one $b$ has already been generated from one $a$. At step $7$, a new $a$ is generated, and thus we reinsert $b$ in the possible set of active events.

We will see how this control can be implemented in the form of another DFA in the next chapter.

## Supervisors as DES

We can represent a supervisor $S = (\hat{X}, E, \hat{\delta}, \hat{x_0}, \hat{X_m})$ on the same alphabet of the plant $G=(X,E,\delta,x_0,X_m)$. In this case:

* Each time an event is generated by $G$, $S$ executes the same event
* When the supervisor in in a state $\hat{x}$, it sends a _control input_ $A_s(\hat{x})$ to the plant, containing all events active in $S$ from $\hat{x}$.

The evolution of the loop can be described in these passages:

1. At the beginning, we have the plant $G$ in the initial state $x = x_0$, and the supervisor in its initial state $\hat{x} = \hat{x_0}$.
2. Then, we define $w = \epsilon$.
3. The production of the word $w$ triggers the production of the control input $\xi_w = A_S(\hat{x})$ on the supervisor.
4. The plant $G$ now generates an event $e \in A_g(x) \cap \xi_w$ (meaning that the generated event must be an active event from state $x$, but also part of the control input of $S$) and proceeds to a state $x' = \delta(x,e)$ normally, like in any DFA.
5. The supervisor executes $e$ and moves normally to $\hat{x}' = \hat{\delta}(\hat{x},e)$.
6. We now say that $w = we$, $x = x'$, $\hat{x} = \hat{x}'$, and then start from 3 with these new values.

> [!help]
> 
> I am pretty sure the above picture is wrong: in $S$, the transition from $\hat{x_1}$ to $\hat{x_0}$ should be done by consuming $a$, not $f$, so the two would be swapped.

Basically, when we generate a $b$ after one $a$, the supervisor moves to state $\hat{x_1}$, where $b$ is no longer an active event.

In this representation, a word generated by $G$ is also generated by $S$. This means that we can generalize the concept of this closed-loop system as the automaton:

$$
S /G = G \cap S = G \mid \mid S
$$

> [!help]
> 
> We can write $G \cap S$ = $G \mid \mid S$ since $G$ and $S$ have the same language.

whose closed language is $L(S/G) = L(G) \cap L(S)$ and whose marked language is $L_m(S/G) = L_m(G) \cap L_m(S)$.

DFA supervisors $S$ fall into two categories:

1. **Non-marking**: meaning that the supervisor doesn't specify which words are final, and thus all words that yield a final state in the plant are considered final ($\hat{X}_m = \hat{X}$). This means that the marked language becomes $L_m(S/G) = L_m(G) \cap L_m(S) = L_m(G) \cap L(S)$.
2. **Marking**: meaning that the final words are specified by the supervisor, and thus a word is final only if it yields a final state on the plant _and_ on the supervisor ($\hat{X}_m \subset \hat{X}$).
