# Fault Diagnosis

With the term "**fault**", we describe an undesirable event which is typically not observed directly. From this assumption, we can define two other concepts linked to that of fault, which are:

1. **Fault diagnosis**, which consists in the activity of detecting faults based on partial observations of the system
2. **Diagnosability analysis**, which consists in the activity of establishing if detecting a fault after a finite number of event observations is feasible.

Considering the definition of automatons, we can define a faulty system as a DFA $G=(X,E,\delta,x_0)$ where the set of final states is unknown. This DFA represents both the normal and the faulty behaviors, which are described by $L(G)$. The alphabet can be partitioned in:

* Observable events: $E_o$
* Unobservable events: $E_{uo} = E_f \cup E_{reg}$
	* Fault events: $E_f$
	* Regular events: $E_{reg}$

> [!info] Assumptions
> 
> We need to make sure that the following assumptions are met:
> 
> 1. $G$ has no _dead states_ (for the sake of simplicity)
> 2. $G$ has no cycles of unobservable events (to ensure that $G$ does not encounter an unobservable infinite loop of events)

## Projection and Inverse Projection

> [!info] Projection operator
> 
> Given a DFA $G$ with $E = E_o \cup E_{uo}$, the projection operator on the set of observable events is $P : E^* \to E_o^*$, defined as:
> 
> $$
> \begin{cases}
> P(\epsilon) = \epsilon \\
> P(e) = e & \text{if } e \in E_o \\
> P(e) = \epsilon & \text{if } e \in E_{uo} \\
> P(se) = P(s)P(e) & \text{if } s \in E^* \land e \in E
> \end{cases}
> $$

The projection operator fundamentally takes a word $w$ and erases the unobservable events that compose that word.

> [!info] Inverse projection operator
> 
> Given a DFA $G$ with $E = E_o \cup E_{uo}$, the projection operator on the set of observable events is $P^{-1} : E_o^* \to 2^{L(G)}$, defined as:
> 
> $$
> P^{-1}(w) = \{s \in L(G) \mid P(s) = w\}
> $$

The inverse projection operator acts in the opposite way of the projection one: it associates a set of observable events to the $n$ strings in the language $G$ whose projection is $w$.

There are two different notions to indicate a string or a word:

* $s \in E^*$ refers to a string of events generated by $G$
* $w \in E_o^*$ refers to an _observed word_ (the observable projection of a generated string)

This means that if we have a DFA $G$ that generates a string $s \in E^*$, an external agent will observe the generated word $w = P(s) \in E_o^*$ (meaning, the word generated by the firing of all observable events). This means that an agent _can't_ see the result of unobservable events firing: we can define:

> [!info] Set of consistent strings and states
> 
> 1. A set of _string_ (succession of states) consistent with the observation of $w$: $S(w) = P^{-1}(w) \subseteq L(G)$
> 2. A set of _states_ consistent with the observation of the final word $w$

Example, in the following automaton:

![](https://i.imgur.com/yuvTKq3.png)

The word $w = bb$ can be generated with two different productions:

$$
x_0 \to^b x_1 \to^{\epsilon_1} x_0 \to^b x_1
$$

or

$$
x_0 \to^b x_1 \to^{\epsilon_1} x_0 \to^b x_1 \to^{\epsilon_1} x_0
$$

This means that:

* The set of consistent strings $S(bb)$ is $\{b\epsilon_1 b, b\epsilon_1 b\epsilon_1\}$
* The set of consistent states $X(bb)$ is $\{x_0, x_1\}$

We can also introduce the notion of _support_:

> [!info] Support
> 
> Given a string $s \in E$, the support of $s$ is:
> 
> $$
> ||s|| = \{e \in E \mid \lvert s\rvert_e > 0\} \subseteq E
> $$
> 
> which is the set of events appearing at least once in the string.

## Diagnosis

Given a DFA $G$, we want to determine if, during the production of a word $w \in E_o^*$, a fault has occurred (a transition with a label in $E_f$ has produced $w$).

To do this, we define a _diagnosis function_.

### Diagnosis Function

> [!info] Diagnosis function
> 
> Given a DFA $G$ with $E = E_o \cup E_{uo}$ and a set of fault events $E_f \subseteq E_{uo}$, we call _diagnosis function_ a function:
> 
> $$
> \varphi : E_o^* \to \{N,F,U\}
> $$
> 
> which associates a word $w \in E_o^*$ to a diagnosis state $\varphi(w) \in \{N,F,U\}$:
> 
> 1. $\varphi(w) = N$: no fault, if $\forall s \in P^{-1}(w) \mid \lvert \lvert s  \rvert \rvert \cup E_f = \emptyset$.
> 2. $\varphi(w) = F$: fault, if $\forall s \in P^{-1}(w) \mid \lvert \lvert s  \rvert \rvert \cup E_f \neq \emptyset$.
> 3. $\varphi(U) = N$: uncertain, if $\exists s', s'' \in P^{-1}(w) \mid \lvert \lvert s' \rvert \rvert \cup E_f = \emptyset \land \lvert \lvert s'' \rvert \rvert \cup E_f \neq \emptyset$.

Basically, the diagnosis function first computes the inverse projection of the given word, to have a set of all possible strings that project into the word $w$. Then, it calculates the support function for each string, to check whether in any of these a faulty state was present. Here, we have that:

1. If no faulty state is found, the word is not faulty
2. If two different strings have been found, where one has a faulty state and the other one doesn't, then the result is uncertain (because we cannot know which of these two "paths" was taken to generate $w$)
3. If a faulty state is found, the word is faulty.

If we have $n$ fault classes $E_{f,1}, E_{f,2}, \dots, E_{f,n}$, we need to solve the diagnosis problem for each class, meaning we need to build $n$ diagnosis function for each fault class.

### Diagnoser

We can apply our just defined diagnosis function to the concept of _diagnoser_:

> [!info] Diagnoser
> 
> Given a DFA $G$ with $E = E_u \cup E_{uo}$ and set of fault events $E_f \subseteq E_{uo}$, a diagnoser is a DFA:
> 
> $$
> Diag(G) = (Y, E_o, \delta_y, y_0)
> $$
> 
> on alphabet $E_o$ such that:
> 
> $$
> Y \subseteq (X \times \{N\}) \cup (X \times \{F\})
> $$
> 
> where $\delta^*_y$ is defined if and only if:
> * All pairs $(x,N)$ where $x$ can be reached in $G$ executing a string consistent with $w$ that does not contain a fault event
> * All pairs $(x,F)$ where $x$ can be reached in $G$ executing a string consistent with $w$ that does contain a fault event

Basically, a diagnoser is a DFA in which each state is labeled with a state name from the DFA $G$ and the result of a diagnosis function $\varphi$ of either $N$ or $F$ labeled $\gamma_i$. This is done so that we can say if a state $y$ is faulty in this way:

1. $\varphi(y) = N$ if all $\gamma_i$ are $N$ (there is no faulty state)
2. $\varphi(y) = F$ if all $\gamma_i$ are $F$ (there are only faulty states)
3. $\varphi(y) = U$ if some $\gamma_i$ are $F$ and some are $N$ (there are faulty and unfaulty states)

As an example, let's consider this automaton $G$ and its supervisor:

![](https://i.imgur.com/ZyJxmAq.png)

The supervisor is the one on the right. Each event is labeled with a symbol from the alphabet $E$ of observable events. Inside each box we have $n$ states which are all the possible states reached in the production of a word. For example, in order to produce $a$ the automaton $G$ might either perform this production:

$$
x_0 \to^a x_2
$$

or this one:

$$
x_0 \to^a x_2 \to^{\epsilon_f} x_0
$$

Looking at the supervisor, we see that we have a label $a$ conducting right to the next state: however, as we saw, the production of the word $w = a$ might contain some unobservable events ($\epsilon_f$), but an outside supervisor has no way to say whether this happened or not. To solve this problem, we consider both production and check if any of these encountered a faulty state. In our case, while the first one didn't, the second one did, so we have:

* $(x_2, N)$ meaning that the production of $w = a$ ending in $x_2$ didn't fire any faulty events
* $(x_0, F)$ meaning that the production of $w = a$ ending in $x_0$ did fire at least one faulty event

Since we have both a faulty and a non-faulty case for the production of $w = a$, $\varphi(y_1)$ is labeled as "uncertain" ($U$), meaning we can't say for sure if the production of this word fired a faulty event or not.

A different case is that of state $y_2$: here, the production of word $w = aa$ is necessarily faulty, since both possible productions:

$$
x_0 \to^a x_2 \to^{\epsilon_f} x_0 \to^a x_2
$$

and

$$
x_0 \to^a x_2 \to^{\epsilon_f} x_0 \to^a x_2 \to^{\epsilon_f} x_0
$$

necessarily trigger the faulty event $\epsilon_f$: both production ending in $x_0$ and $x_2$ are faulty, so $\varphi(y_2) = F$.

### Build a diagnoser

We can design an algorithm that takes as input a DFA $G$ and outputs its diagnoser $Diag(G)$.

1. For all states of $x \in X$ of $G$, compute two different sets:
	1. $D_{reg}(x)$ contains all states reachable from $x$ executing a (possibly empty) sequence of regular, unobservable trainsitions
	2. $D_f(x)$ contains all states reachable from $x$ executing a sequence of unobservable transitions, with at least one fault.
2. Define the initial state of the diagnoser $y_0$ as a set of pairs ($x,\gamma)$, where:
	* $\gamma = N$ if $x$ is reachable from the initial state of $G$ $x_0$ with a sequence of unobservable, non-faulty transactions
	* $\gamma = F$ if $x$ is reachable from the initial state of $G$ $x_0$ with a sequence of unobservable transactions with at least one fault
3. Define $Y = \emptyset$, which will contain all states of the diagnoser at the end, and $Y_{new} = \{y_0\}$, which will be used to add unexplored states.
4. Now we iterate over all states in $y \in Y_{new}$:
	1. For all events $e \in E_o$:
		1. We define 3 different sets:
			* $\alpha(y,e)$, which contains the pairs $(x',\gamma)$ such that, with $(x, \gamma) \in y$ and $e \in E$, $x'$ is reachable in $G$ from $x$ with exactly one e-transition
			* $\beta_1(y,e)$, which contains the pairs $(x'', N)$ such that, with $(x',N) \in \alpha(y,e)$, $x''$ is reachable in $G$ from $x'$ with a sequence of regular transitions.
			* $\beta_2(y,e)$, which contains the pairs $(x'', F)$ such that, with $(x',N) \in \alpha(y,e)$, $x''$ is reachable in $G$ from $x'$ with a sequence of unobservable transitions with at least a fault. Here, if $x'$ can be reached without a fault, then $x''$ can be reached with a fault.
			* $\beta_3(y,e)$, which contains the pairs $(x'', F)$ such that, with $(x',F) \in \alpha(y,e)$, $x''$ is reachable in $G$ from $x'$ with a sequence of unobservable transitions. Here, since $x'$ is reached with a fault, so is $x''$.
			  
			  ![](https://i.imgur.com/GW6evKH.png)
		2. We define $y'$ as the union of $\beta_1, \beta_2, \beta_3$ and $\delta_Y(y,e) = y'$, meaning that the execution of $e$ from $y$ of $Diag(G)$ yields $y'$.
		3. If $y' \not\in Y \cup Y_{new}$, then we add it to $Y_{new}$.
	2. We move $y$ from $Y_{new}$ to $Y$
5. Iterate step 4 until $Y_{new}$ is not empty

With a plant $G$ having a state $X$ of cardinality $n_x$, the cardinality of the state set $Y$ of its diagnoser $n_y$, we have $n_y < 2^{2n_x}$.

## Diagnosability

A DFA $G$ might also be not diagnosable. To understand how, consider a plant that can generate a string $ue_f$ containing a fault. The evolution then continues for a series of steps $n$, until the generated word becomes $s = ue_fv$. If we wait long enough and if the system _is_ undiagnosable, then, when we produce the observation $P(s)$ we can find another string $P(s')$ that contains no fault. This means that the diagnoser can't say if the produced word encountered a fault or not, and thus the word is _undiagnosable_. Diagnosability is the opposite of this property (we can't find a string $s'$ respecting what we said):

> [!info] Diagnosability
> 
> A DFA $G$ with $E = E_o \cup E_{uo}$ and a set of fault events $E_f \subseteq E_{uo}$ is diagnosable if for all strings $ue_f \in L(G)$ such that $e_f \in E_f$ there exists a non-negative integer $n \in N$ such that:
> 
> $$
> s = ue_fv \in L(G), \lvert v \rvert \geq n \rightarrow \not\exists s' \in L(G) \cup (E \textbackslash E_f)^* \text{ such that } P(s) = P(s')
> $$

We want to be able to tell if a DFA $G$ is diagnosable or not. Before doing this, we need to introduce the notion of _uncertain cycle_:

> [!info] Uncertain cycle
> 
> Given $Diag(G)$, a cycle
> 
> $$
> y_{j_1} \to^{e_1} y_{j_2} \to^{e_2} y_{j_3} \dots y_{j_k} \to^{e_k} y_{j_1}
> $$
> 
> is called _uncertain_ if all states are uncertain.

We can now define our diagnosability condition as follows:

> [!info] Diagnosability condition
> 
> A DFA $G$ is diagnosable if its diagnoser does not contain any uncertain cycles.

Let's take the diagnoser from above as an example:

![](https://i.imgur.com/5pRymjG.png)

We can find the following cycles:

Since non of these is uncertain, $G$ is diagnosable.

> [!warning]
> 
> Note that this condition is **sufficient, but not necessary**!

This means that we can have an uncertain cycle in $G$, but this can still be diagnosable. To have a sufficient and necessary condition, we need to introduce the concept of a refined sequence associated to an uncertain cycle.

> [!info] Refined sequence associated to an uncertain cycle
> 
> Given $Diag(G)$ and an uncertain cycle
> 
> $$
> y_{j_1} \to^{e_1} y_{j_2} \to^{e_2} y_{j_3} \dots y_{j_k} \to^{e_k} y_{j_1}
> $$
> 
> We call $y_{j_1}^1$ the refined diagnoser state, which can be obtained from $y_{j_1}$ by removing all non faulty pairs. We thus call a refined sequence associated to $uc$ a sequence of diagnoser states obtained by applying the diagnoser construction from $y_{j_1}^1$ for all occurrences of the string of events $e_1e_2\dots e_k$:
> 
> $$
> y_{j_1}^1 \to^{e_1} y_{j_2}^1 \to^{e_2} y_{j_3}a^1 \dots y_{j_k}^1 \to^{e_k} y_{j_1}^2 \to \dots
> $$


For example, consider this automaton and its diagnoser:

![](https://i.imgur.com/kPQOX5F.png)

The states $y_1, y_2$ compose an uncertain cycle. The refined sequence compared to the cycle (left) thus looks like this:

![](https://i.imgur.com/o0AEeaa.png)

We can prove that a refined sequence either:

* Continues indefinitely
* Eventually halts

In our example, the cycle halted, because $a$ can't be produced, since we removed its destination state $x_1$.

If the refined sequence continues indefinitely, we have an **indeterminate cycle**. Finally, we can have a definitive condition to prove if an automaton is diagnosable:

> [!info] Diagnosability
> 
> A DFA $G$ is diagnosable **if and only if** $Diag(G)$ has _no indeterminate cycles_.

This means that, in our example, $G$ is diagnosable.
