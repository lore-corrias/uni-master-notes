# Nondeterministic Finite Automaton

> [!info]
> A NDFA (Non-deterministic Finite Automaton) is a generalization of the concept of DFA. It is defined as a 5-tuple:
>
>$$
>G = (X,E,\Delta,x_0,X_m)
>$$
> 
> where:
> * $X$ is the finite set of states
> * $E$ is an alphabet
> * $\Delta \subseteq X \times E_\epsilon \times X$ is a transition **relation**, with $E_\epsilon = E \cup \{\epsilon\}$.
> * $x_0 \in X$ is the initial state
> * $X_m \subseteq X$ is the subset of final states

We say that this is a generalization of a DFA because we have a transition **relation** $\Delta$ instead of a function $\delta$: this allows us to have the following properties:

1. Transitions labeled with the empty word $\epsilon$ (called "silent" or "unobservable")
2. States that have **two or more** transitions outgoing with the same label (called "undistinguishable")

## Productions

In NDFAs we have the same concept of productions as that of DFAs: however, due to the introduction of "silent" events, we might have a case like the following, where producing a word $|w| = 4$ takes more than $4$ transitions:

![](https://i.imgur.com/6N1W9zX.png)

In this case, the production of the word $w = abaa$ starting from $x_0$ and reaching $x_0$ is:

$$
x_0 \to^a x_0 \to^\epsilon x_1 \to^b x_0 \to^a x_0 \to^a x_0
$$

We might also have multiple routes for a same word: we can generate $w = abaa$ by leveraging the two transitions from $x_2$ to $x_{3,4}$:

$$
x_0 \to^a x_0 \to^b x_3 \to^a x_4 \to^a x_4
$$

This is the _non-deterministic_ component: for some states, we can take two different routes which are both correct.

## Transitive and reflexive closure of $\Delta$

Like in DFAs, we can define the transitive and reflexive closure of the $\Delta$ relation as:

> [!info] Transitive and reflexive closure of $\delta$
> 
> Given an NFA $G$ the transitive and reflexive closure of the transition relation $\delta$ is the relation $\Delta^* \subseteq X \times E^* \times X$ such that $(x,w,\overline{x}) \in \Delta^*$ **if** there exists a production that starts from $x$ and generates $w$ reaching state $\overline{x}$.

Taking the example from above, $(x_0, abaa, x_0) \in \Delta^*$ and $(x_0, abaa, x_4) \in \Delta^*$.

## Generated and Accepted words

Since NFAs are non-deterministic, we need to slightly tweak the definitions from DFAs for generated and accepted words. We say that a word is:

> [!info] Generated and Accepted words in an NFA
> 
> * Generated, if the NFA has a state $x \in X$ such that there exists a production to generate $w$ from the initial state (doesn't matter if it ends in a final state) $\to (x_0, w, x) \in \Delta^*$.
> * Accepted, if the NFA has a state $x \in X_m$ such that there exists a production to generate $w$ from the initial state, but ending in a final state $\to (x_0, w, x) \in \Delta^*$

This means that for _accepted_ words we only care if there exists _at least one_ production from all of the possible ones of the word $w$ which ends in a final state.

## Generated and Accepted Languages

The same definitions for DFAs apply for NFAs too:

> [!info] Generated Language
> 
> Given an NFA $G$, its generated language is the set of all generated words:
> 
> $$
> L(G) = \{w \in E^*\ |\ \text{there exists } x \in X\ :\ (x_0, w, x) \in \Delta^*\} \subseteq E^*
> $$

> [!info] Accepted Language
> 
> Given an NFA $G$, its accepted language is the set of all accepted words:
> 
> $$
> L_m(G) = \{w \in E^*\ |\ \text{there exists } x \in X_m\ :\ (x_0, w, x) \in \Delta^*\} \subseteq L(G)
> $$

The property from DFAs also holds
$$
L_m(G) \subseteq \overline{L_m(G)} \subseteq L(G) = \overline{L(G)}
$$

And we also have that the class of languages accepted by NFAs on an alphabet $E$ is:

$$
L_{NFA} = \{L \subseteq E^*\ |\ \text{there exsists an NFA G}: L = L_m(G)\}
$$

## Properties and differences from DFAs

This are all the possible state/automaton classifications for DFAs

* Reachability
* Co-reachability
* Blocking
* Dead
* Non-blocking
* Trim
* Reversible

that apply to NFAs as well. However, there are some differences. 

Notably, the property "a DFA $G$ is non-blocking if and only if $\overline{L_m(G)} = L(G)$" does not hold for NFAs, as a word can be generated by multiple productions. We can actually say that:

> [!info] Blocking NFA definition
> 
> An NFA $G$ is blocking if $\overline{L_m(G)} \subset L(G)$.

## Equivalence of NFAs and DFAs

If we define the following classes:

* $L_{DFA}$ as the class of languages accepted by DFAs
* $L_{NFA}$ as the class of languages accepted by NFAs

### NFA to DFA algorithm

We can say that $L_{DFA} \subseteq L_{NFA}$, as DFAs are a subset of NFAs. In order to demonstrate that $L_{DFA} = L_{NFA}$ we need to show that the reverse of the first property holds. In order to do this, we design an algorithm that allows us, given an NFA $G$, to determine a DFA $G'$ equivalent to it. 

These are the steps that we take to design such an algorithm. We consider to have:

* An input of an $NFA\ G$
* An output of a $DFA\ G'$


1. Take all states $x$ of $G$ and compute:
   
   $$
   D_\epsilon(x) = \{\overline{x} \in X \mid (x, \epsilon, \overline{x}) \in \Delta^*\}
   $$
   
   which contains all states reachable from $x$ with zero or more $\epsilon$ transition
2. For all states $x$ of $G$ and all symbols $e \in E$ compute:
   
   $$
   D_e(X) = \{\overline{x} \in X \mid (x,e,\overline{x}) \in \Delta\}
   $$
   
   containing all states reachable from $x$ with only one e-transition.
3. Let $x'_0 = D_\epsilon(x_0)$: the initial state of $G'$ becomes the set of states reachable in $G$ from $x_0$ with zero or more e-transitions
4. Let $X' = \emptyset$ and $X'_{new} = \{x'_0\}$. We will use $X'_{new}$ as a set to add states as we explore them, while $X'$ will contain all of the states of the resulting DFA $G'$.
5. Now we iterate for all states $x' \in X'_{new}$:
	1. We iterate all events $e \in E$
		1. We define two different sets:
			* $\alpha(x',e)$, which contains all states reachable in $G$ from a state $x \in x'$ with only one e-transition.
			* $\beta(x',e)$, which contains all states reachable in $G$ from a state $x \in \alpha(x',e)$ with zero or more e-transition.
		2. We now define the new state $\bar{x}'$ as the result of $\beta(x',s)$, and its transition function value as $\delta'(x',e) = \bar{x}'$.
		3. If $\bar{x}'$ was not either in $X'$, nor in $X'_{new}$, we add it to $X'_{new}$
	2. We move $x'$ from $X'_{new}$ to $X'$.
6. Iterate step 5 until $X'_{new}$ is empty
7. We define the set of final states as $X'_m = \{x' \in X' \mid x' \cap X_m \neq \emptyset\}$ (a state is final only if it contains at least one final state of $G$)

As an example, consider the following NFA:

![](https://i.imgur.com/1niN6Il.png)

We want to compute the relative DFA.

The first step is to define $x_0'$. This is the set of all states which are reachable from $x_0$ with zero or more e-transition. In this case, the only such states are $x_0$ itself, $x_2$ (1 e-transition) and $x_3$ (two e-transitions), so we have:

$$
x_0' = D_\epsilon(x_0) = \{x_0,x_2,x_3\}
$$

we now add $x_0'$ to $X'_{new}$ and start iterating step 5. We begin by applying the steps to $x_0'$, considering the symbol $a$. We have:

* $\alpha(x_0', a)$: we need to take all the states in $x_0'$ and calculate $D_a(x_i')$ on each one. $D_a(x_i')$ would be the set of states reachable from $x_i'$ by executing exactly one $a$. So we have:
	* $D_a(x_0)$ = $\emptyset$, since there is no transition with label $a$ from it
	* $D_a(x_2)$ = $\emptyset$, for the same reason as above
	* $D_a(x_3) = \{x_4,x_5\}$, since we have two paths with label $a$ from $x_3$.
	so, our value of $\alpha(x_0', a) = D_a(x_0) \cup D_a(x_2) \cup D_a(x_3) = \{x_4,x_5\}$
* $\beta(x_0',a)$: now we need to iterate the states of $\alpha(x_0',a)$ and calculate $D_\epsilon(x_i')$ on each of them. $D_\epsilon(x_i')$ would be the set of states reachable from $x_i'$ with zero or more $\epsilon$-transition. So we have:
	* $D_\epsilon(x_4) = x_4$, since there is no other $\epsilon$-transition
	* $D_\epsilon(x_5) = x_5$, since there is no other $\epsilon$-transition
	so, our value of $\beta(x_0', a) = D_\epsilon(x_4) \cup D_\epsilon(x_5) = \{x_4,x_5\}$

We can now say that the transition from $x_0'$ to $x_1'$ consuming $a$ is $\delta'(x_0',a) = x_1' = \{x_4, x_5\}$. So we have defined both a step and an arc to that step.

Now we would have to iterate the same steps as above with $x_0'$, but considering the symbol $b$. We can calculate that both $\alpha = \beta = \emptyset$, so $\delta'(x_0',b)$ is _not defined_.

We now add the state $x_0'$ to $X'$ and move $x_1'$ to $X_{new}$. We now apply the same steps to $x_1'$ all over again, until $X'_{new}$ is not empty. This is the final resul table:

![](https://i.imgur.com/fjIkOSg.png)

We stop at $x_2'$ since the $\{x_1,x_4\}$ and $\{x_0,x_2,x_3\}$ are both already present in $X'$. We choose $X'_m=\{x_0'\}$ as the final state, since only $x_0'$ contains $x_2$ (which is the final state of $G$).

Graphically, the resulting DFA compared with the original NFA is:

![](https://i.imgur.com/coZZKws.png)

> [!info] Number of nodes of a DFA built from an NFA
> 
> Given an NFA $G$ with a state set $X$ of cardinality $n$ and $G'$ the equivalent DFA with a state set $X'$ of cardinality $n'$, it holds:
> 
> $$
> n' < 2^n
> $$
